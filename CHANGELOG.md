# Changelog

## 1.1.0 — 2026-11-03

- Every value adjustable for all suppressors at once, per value with a mode: off / set / add / percent, plus min/max limits, exceptions and an only-these list.
- New values: Recoil, Loudness, Weight (besides Ergonomics, Accuracy, Velocity, DurabilityBurn, HeatFactor, CoolFactor).
- Own `config.json` (created on first start, migrates the old settings unchanged). BetterSuppressors is no longer needed; if present, its fixed numbers are taken back.

## 1.0.0 — 2026-11-03

- First release as a standalone repository (SPT 4.1.6).
